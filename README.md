# Revamp Realty Private Limited Website

This is a complete static website package for REVAMP REALTY PRIVATE LIMITED.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this ZIP to the repository root.
3. In GitHub, open Settings > Pages.
4. Set the source to the main branch and root folder.
5. Publish.

## Included

- 50+ static HTML pages plus 18 project detail pages.
- Responsive premium UI with dark mode, mega menu, search, project filters, comparison, calculators, chat, forms, and portals.
- Logo assets, favicon, project visuals, office visuals, master plan, floor plan, hero image, documents, sitemap.xml, robots.txt, manifest, and schema.org metadata.
- Front-end only forms ready for CRM, email, payment, authentication, and analytics integration.

## Before public launch

Official RERA numbers, approvals, pricing, inventory, legal text, financial data, and corporate registration details must be verified by Revamp Realty's legal and compliance teams.
